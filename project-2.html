Line Following Robot

A compact robotics project designed to autonomously follow a line using infrared sensors, real-time motor control, and a tuned control strategy for stability and speed.

← Back to Projects Contact

Role

Design, assembly, wiring, firmware, testing, and documentation.

Tech Stack

  • Microcontroller (e.g., Arduino-class)
  • IR line sensor array
  • DC motors + motor driver
  • Control logic (thresholding / PID)

Goal

Stable line tracking, smooth turns, and reliable recovery when leaving the track.

Status

Prototype completed and iterated through real track testing.

Overview

This robot detects a contrasting line (typically black on white) using infrared reflectance sensors. The firmware computes an error signal based on sensor readings and adjusts motor speeds to keep the line centered.

System Architecture

  • Sensing: IR sensors read reflectance values and identify line position.
  • Control: error computation + motor correction (proportional or PID tuning).
  • Actuation: motor driver modulates speed/direction for left and right motors.
  • Power: battery + regulated supply to logic and motors.

Build & Testing Notes

  • Sensor calibration performed under multiple lighting conditions.
  • Mechanical alignment improved tracking accuracy and reduced oscillations.
  • Control tuning focused on fast cornering without overshoot.
  • Recovery behavior implemented for line loss scenarios.

Results

  • Consistent tracking on straight segments and moderate curves.
  • Improved cornering after tuning control parameters.
  • Stable behavior under typical indoor lighting conditions.

Lessons Learned

  • Mechanical alignment matters as much as software control.
  • Sensor placement and calibration directly impact stability.
  • Incremental tuning with real track tests is essential.
